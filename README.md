# MiniContes Studio V2

Version indépendante du projet SuspenseLingo.

## Déploiement Streamlit Cloud
1. Téléversez `app.py`, `requirements.txt` et `packages.txt` dans le dépôt MiniContes-Studio uniquement.
2. `packages.txt` doit contenir exactement `ffmpeg`.
3. Sur Streamlit Cloud, choisissez `app.py` comme fichier principal, puis redémarrez l’application.

## Nouveautés V2
- Narration IA en ligne avec Edge TTS; aucune voix système locale requise.
- Choix de langue : français, arabe et anglais.
- Choix du style de voix du narrateur.
- Option d’une voix distincte pour les phrases entre guillemets.
- Export vidéo vertical 720×1280 avec mouvement de caméra doux.
- Illustrations stylisées générées par le programme.

## Limites et confidentialité
- Edge TTS nécessite Internet. La disponibilité et les conditions d’utilisation du service peuvent changer; ne présumez pas d’une gratuité commerciale garantie.
- Le texte envoyé au service de synthèse vocale est traité en ligne. N’envoyez pas de données sensibles.
- Les scènes sont des illustrations programmatiques avec animation de caméra, pas des séquences vidéo entièrement générées par IA.
- La liste des voix peut évoluer. Vérifiez les voix disponibles si un identifiant n’est plus accepté.
